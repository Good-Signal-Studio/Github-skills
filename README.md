# Github-skills
Good Signal Studio's Github Skills, templates for great Github etiquette.

## Branches and pull requests

Use [GitHub Flow](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/github-flow/SKILL.md) for short-lived task branches from `dev` and PRs back to `dev`. Use [Git Flow](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/git-flow/SKILL.md) for the approved promotion from `dev` to `main`. Install both complete skill folders, including their references, from personal source revision `649e340019a49f29d27bc940f0822d2c815dff8e`.

Use the [PR format](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/pr-template/SKILL.md), [review gate](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/review-gate/SKILL.md) and [review comments](https://github.com/Jeff-Kazzee/github-skills/blob/649e340019a49f29d27bc940f0822d2c815dff8e/review-comments/SKILL.md). Show Jeff the exact text and destination and wait for approval before posting or editing PR text or comments. Each merge requires approval of the checked head.
