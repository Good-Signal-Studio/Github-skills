# Security reporting

Do not report vulnerabilities, credentials or private project instructions in a
public issue. Contact the repository owner through an existing private channel.
No dedicated reporting address or response-time commitment is established here.

The installer writes repository files and preserves a recovery journal during
an apply. That journal can contain prior instruction text. Keep it private. Read
[the enrolment guide](docs/enrolment.md) before recovery. Review imported skill
code before running it. Installation does not execute the copied scripts.
